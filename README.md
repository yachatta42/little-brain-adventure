# 小小腦力探險隊

每天 5–10 分鐘的繁體中文思考挑戰網站，適合親子一起玩。

## 程度與題庫
- **小一**：以基礎觀察、語文與數感題為主，加入少量有趣的小挑戰。
- **小二**：以規則推理、條件判斷與兩步驟題為主。
- **小三**：增加多步驟、綜合推理與資料判讀。
- **目前共 250 題**：語文表達 40 題；數學推理、觀察與規律、分類與邏輯、生活與空間、空間推理、資料判讀、自然探究各 30 題。
- **國語題加強閱讀能力**：包含詞語理解、句意判斷、短文細節、主旨、因果推論與閱讀整合。
- 題型以選擇、多選、排序、配對及簡短數字填答為主，僅保留少量需要自行表達想法的題目。
- **答對的題目會記錄為已熟練**，之後不再抽出；答錯的題目仍會保留在輪替題庫中。熟練紀錄保存在使用者自己的瀏覽器。

## 使用方式
直接以新版 Chrome、Edge、Safari 或 Firefox 開啟 `index.html` 即可。網站不需登入；探險紀錄只保存在使用者自己的瀏覽器。

## GitHub Pages
在 Settings → Pages → Build and deployment → Source 選擇 GitHub Actions。推送 `main` 後會自動檢查題庫並部署。
