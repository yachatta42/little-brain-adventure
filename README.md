# 小小腦力探險隊
每天 5–10 分鐘的繁體中文思考挑戰網站。

## 功能
- 小一挑戰、小二標準、小三進階三種程度。
- 內含 117 題、8 個學習領域，支援單選、多選、填答、排序、配對與開放回答。
- 不將開放式回答硬判對錯；客觀題支援中文數字、全形數字與常見單位。
- 不需登入、資料庫或第三方服務；進度儲存在本機瀏覽器。

## 本機使用
直接以新版 Chrome、Edge、Safari 或 Firefox 開啟 index.html。網站使用瀏覽器內建 DecompressionStream 解開內嵌的 gzip 網頁內容；原始可編輯版本請見專案發佈附件或下載包。

## GitHub Pages
Settings → Pages → Build and deployment → Source 選 GitHub Actions。推送 main 後會自動部署。
